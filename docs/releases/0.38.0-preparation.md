## Semantic Versioning classification

- Previous version: `0.37.0`
- Chosen version: `0.38.0`
- Release date: `2026-11-03`
- Change level: `minor`

tmux-play now admits a resumed Claude call whose settings select the provider-default model, which 0.37.0 rejected with an `AgentCallSettingsError`; an embedding caller relying on that rejection sees the call run instead.
Claude model discovery now probes the native binary before opening the SDK, so a missing binary reports the adapter's install guidance rather than an SDK spawn failure.
Changing which call settings are admitted is more than a patch; under 0.x it takes a minor release, and no exported type or signature changes.
Spex takes this version next to run resumed Claude steps on a third-party provider and to read Claude's model catalog inside its packaged app.
