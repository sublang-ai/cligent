# 0.40.0 development risk and next-version remediation

On 2026-11-18 the owner explicitly authorized deferring
[GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)
for both testing and formal publication, with repair deferred to the next version.
This is a recorded risk acceptance, not a security fix or a clean full audit.

The deferral is limited to Cligent 0.40.0 and its rc prereleases, the locked
picomatch 4.0.4 development-only graph and this single advisory. Production and
installed-production audits, other findings and all functional checks remain
strict. Every verification retains the raw report and an explicit decision.
The ordinary complete CI, release publisher and merge requirements still apply.

Next-version backlog:

- Repair the matcher dependency graph using an upstream supported patched
  release, or a separately reviewed development-tool replacement if necessary.
- Verify affected lint, parser, build and test consumers and both dependency
  audits; preserve the original finding and remediation evidence.
- Remove the version-bounded exception after repair. Versions other than 0.40.0
  and its rc prereleases already refuse the deferred finding automatically.
