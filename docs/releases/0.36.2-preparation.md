## Semantic Versioning classification

- Previous version: `0.36.1`
- Chosen version: `0.36.2`
- Release date: `2026-11-02`
- Change level: `patch`

This patch fixes native Windows execution under the existing Agent options and final-response contract, rather than adding a new caller-facing task API.
The owner explicitly chose a PATCH release after reviewing the actual SPEX, Playbook and SLC consumers and accepting two bounded compatibility exceptions: removal of unused legacy wrapper exports/mapping fields and the known raw U+2028/U+2029 SDK parsing regression.
Neither exception is claimed fixed, and this classification is not a blanket compatibility guarantee for unknown external users of those legacy exports or output cases.
Normal Codex startup remains the direct official SDK path without restoring a wrapper, startup hook or output patch.
The ordinary public runtime Node floor, runtime dependencies and Agent SDK pins remain unchanged; development linting has a separately documented newer Node requirement.
SLC's existing ^0.36.1 range admits this version, so no SLC release is required solely for the dependency range.
